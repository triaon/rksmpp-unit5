# Задание 2: Фотоальбом «Мои растения» с кнопкой «Сделать фото»
Функционал приложения:

Необходимо создать личный фотоальбом комнатных растений, куда пользователь добавляет фотографии своих растений. Фото сохраняются в приватной папке приложения, но при желании пользователь может экспортировать их в общую галерею.

Функционал, который нужно реализовать:

- Кнопка «Сделать фото» — открывает камеру — сохраняет фото в getExternalFilesDir(Environment.DIRECTORY_PICTURES);
- Список всех сделанных фото растений в LazyVerticalGrid;
- Приложение запрашивает CAMERA и WRITE_EXTERNAL_STORAGE (если нужно).

Требования к файлам:

- Имя файла — IMG_${SimpleDateFormat("yyyyMMdd_HHmmss")}.jpg;
- Список фото — сканирование папки при запуске и при добавлении нового фото.

Требования к UI:

- Главный экран — сетка фото (LazyVerticalGrid, 3 колонки);
- Пустой экран — текст «У вас пока нет фото» + кнопка «Сделать первое фото».

# Задание 3: Фотоальбом «Мои растения» с экспортом в галерею
Функционал приложения:

Доработать задание 2 из Модуля 5. Необходимо реализовать экспорт фото растений в общую галерею.

Функционал, который нужно добавить:

- Пункт «Экспорт в галерею» — сохраняет копию фото в MediaStore (чтобы фото появилось в стандартной галерее телефона, папка Pictures/MyPlants).

Требования к UI:

- Главный экран — сетка фото (LazyVerticalGrid, 3 колонки);
- Пустой экран — текст «У вас пока нет фото» + кнопка «Сделать первое фото»;
- Добавить DropdownMenu и пункт «Экспорт в галерею» у каждого изображения в LazyVerticalGrid;
- После экспорта — показывать Snackbar «Фото добавлено в галерею».
