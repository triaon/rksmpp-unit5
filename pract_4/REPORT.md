# Задание 4: Приложение «Список покупок» с хранением в Room и DataStore
Доработать приложение «Список покупок» с использованием:

- Разово импортировать покупки из JSON файла (assets/purchases.json) в СУБД SQLite при помощи Room;
- Реализовать функционал добавления, изменения и удаления покупки в СУБД SQLite при помощи Room;
- Добавить возможность изменения цвета фона купленной позиции, c сохранением значения в DataStore;
- Добавить в TopAppBar управляющий элемент (Switch): «Цвет купленных».

Дополнительно в приложении:

- Отметка «куплено» чекбоксом прямо в списке;
- Добавление и редактирование покупки через диалоговое окно (название, количество, заметка);
- Отдельный экран деталей покупки с кнопками «Изменить» и «Удалить».
