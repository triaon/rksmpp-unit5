# Задание 1: Дневник путешествий с записью данных в файл
Функционал приложения:

Пользователь ведёт дневник путешествий в приложении. Каждая запись о поездке сохраняется в отдельном файле внутри приватной папки приложения и недоступна извне. Список записей должен обновляться быстро и без полного пересканирования папки при каждой операции.

- Поле ввода для заголовка (опционально, например название города) и большое поле для текста записи;
- Кнопка «Сохранить»;
- Список всех сохранённых записей в LazyColumn (с датой и первыми 30–40 символами текста);
- При клике на запись — открывается экран чтения/редактирования;
- Возможность удаления записи (через контекстное меню);
- При запуске приложения список загружается автоматически.

Требования к хранению:

- Каждая запись сохраняется в отдельный файл в context.filesDir;
- Имя файла — timestamp_[опционально_заголовок].txt.

Не перегружать весь список целиком при добавлении и удалении записи!

- При сохранении новой записи — добавлять её вручную в начало списка (без повторного сканирования всей папки);
- При удалении записи — удалять её из текущего списка по имени файла (без пересканирования);
- Полное сканирование папки и загрузка всех записей делается только один раз — при запуске приложения (в init ViewModel).

Требования к UI:

- Главный экран: список записей (LazyColumn) + FAB-кнопка «+ Новая запись»;
- Экран записи: заголовок (опционально), многострочный TextField, кнопки «Сохранить» и «Назад»;
- При долгом нажатии на запись — контекстное меню с пунктом «Удалить»;
- Пустой экран: текст «У вас пока нет записей» + подсказка «Нажмите +, чтобы создать первую».
